동적 메모리 할당 (malloc, free)

C언어 · 2025.10.29

동적 메모리 할당이란?

프로그램 실행 중에 필요한 만큼의 메모리를 할당받아 사용하는 것을 동적 메모리 할당이라고 합니다. 컴파일 타임에 크기가 정해지는 정적 메모리와 달리, 런타임에 필요한 메모리 크기를 결정할 수 있습니다.

주요 함수들

1. malloc() - Memory Allocation

#include <stdlib.h>

int *arr = (int *)malloc(5 * sizeof(int));
if (arr == NULL) {
    printf("메모리 할당 실패\n");
    return 1;
}

// 메모리 사용
for (int i = 0; i < 5; i++) {
    arr[i] = i * 10;
}

// 반드시 메모리 해제
free(arr);

malloc()은 지정된 바이트 수만큼의 메모리를 할당하고, 할당된 메모리의 시작 주소를 반환합니다. 할당에 실패하면 NULL을 반환하므로 반드시 체크해야 합니다.

2. calloc() - Contiguous Allocation

int *arr = (int *)calloc(5, sizeof(int));
// 5개의 int 크기 메모리를 할당하고 0으로 초기화

if (arr != NULL) {
    // 모든 요소가 0으로 초기화됨
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);  // 0 0 0 0 0
    }
    free(arr);
}

calloc()은 malloc과 유사하지만, 할당된 메모리를 모두 0으로 초기화합니다. 첫 번째 인자는 요소의 개수, 두 번째 인자는 각 요소의 크기입니다.

3. realloc() - Re-allocation

int *arr = (int *)malloc(5 * sizeof(int));

// 크기를 10개로 확장
arr = (int *)realloc(arr, 10 * sizeof(int));
if (arr == NULL) {
    printf("재할당 실패\n");
    return 1;
}

// 기존 데이터는 유지됨
free(arr);

realloc()은 이미 할당된 메모리의 크기를 변경합니다. 기존 데이터는 보존되며, 새로운 메모리 영역으로 이동할 수도 있습니다.

4. free() - Memory Deallocation

int *ptr = (int *)malloc(sizeof(int));
*ptr = 100;

free(ptr);      // 메모리 해제
ptr = NULL;     // 댕글링 포인터 방지

free()는 동적으로 할당된 메모리를 해제합니다. 메모리 누수(memory leak)를 방지하기 위해 반드시 호출해야 합니다.

실전 예제: 동적 2차원 배열

int rows = 3, cols = 4;

// 행 포인터 배열 할당
int **matrix = (int **)malloc(rows * sizeof(int *));

// 각 행마다 열 할당
for (int i = 0; i < rows; i++) {
    matrix[i] = (int *)malloc(cols * sizeof(int));
}

// 배열 사용
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        matrix[i][j] = i * cols + j;
    }
}

// 메모리 해제 (역순으로)
for (int i = 0; i < rows; i++) {
    free(matrix[i]);
}
free(matrix);

주의사항

  • 항상 NULL 체크: 할당 실패 가능성을 항상 고려해야 합니다.
  • 반드시 메모리 해제: 할당한 메모리는 반드시 free()로 해제해야 합니다.
  • 이중 해제 금지: 같은 메모리를 두 번 해제하면 안 됩니다.
  • 댕글링 포인터 방지: free() 후에는 포인터를 NULL로 설정하는 것이 좋습니다.
  • 메모리 누수 주의: 프로그램 종료 전에 모든 동적 메모리를 해제해야 합니다.

정리

동적 메모리 할당은 유연한 메모리 관리를 가능하게 하지만, 올바르게 사용하지 않으면 메모리 누수나 프로그램 오류를 일으킬 수 있습니다. 할당과 해제를 정확히 짝지어 사용하는 습관을 들이는 것이 중요합니다.
