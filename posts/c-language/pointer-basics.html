포인터의 기본 개념과 활용

C언어 · 2025.10.28

포인터란?

포인터(Pointer)는 메모리 주소를 저장하는 변수입니다. C언어에서 가장 강력하면서도 초보자들이 가장 어려워하는 개념 중 하나입니다. 포인터를 제대로 이해하면 메모리를 효율적으로 관리하고 복잡한 자료구조를 구현할 수 있습니다.

포인터의 기본 문법

1. 포인터 선언

int *ptr;        // 정수형 포인터
char *str;       // 문자형 포인터
double *dptr;    // 실수형 포인터

포인터를 선언할 때는 자료형 뒤에 * 기호를 붙입니다. 이는 "해당 자료형을 가리키는 포인터"를 의미합니다.

2. 주소 연산자 (&)

int num = 10;
int *ptr = &num;  // num의 주소를 ptr에 저장

printf("num의 값: %d\n", num);
printf("num의 주소: %p\n", &num);
printf("ptr이 가리키는 주소: %p\n", ptr);

& 연산자는 변수의 메모리 주소를 반환합니다. 위 코드에서 ptr은 num이 저장된 메모리 위치를 가리키게 됩니다.

3. 역참조 연산자 (*)

int num = 10;
int *ptr = &num;

printf("ptr이 가리키는 값: %d\n", *ptr);  // 10 출력
*ptr = 20;  // ptr이 가리키는 위치의 값을 20으로 변경
printf("num의 값: %d\n", num);  // 20 출력

* 연산자는 포인터가 가리키는 주소에 있는 실제 값에 접근합니다. 이를 "역참조(dereferencing)"라고 합니다.

포인터의 활용

함수에서 값 변경하기

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 5, y = 10;
    printf("Before: x=%d, y=%d\n", x, y);

    swap(&x, &y);

    printf("After: x=%d, y=%d\n", x, y);
    return 0;
}

포인터를 사용하면 함수 내에서 원본 변수의 값을 직접 변경할 수 있습니다. 이는 Call by Reference 방식으로, 함수가 변수의 주소를 받아 원본 데이터를 수정합니다.

주의사항

  • 초기화하지 않은 포인터 사용 금지: 선언만 하고 초기화하지 않은 포인터를 사용하면 예상치 못한 메모리 영역에 접근하여 프로그램이 crash될 수 있습니다.
  • NULL 포인터 체크: 포인터를 사용하기 전에 NULL인지 확인하는 습관을 들이세요.
  • 메모리 범위 체크: 배열 포인터를 사용할 때는 항상 배열의 범위를 벗어나지 않도록 주의해야 합니다.

정리

포인터는 C언어의 핵심 개념으로, 메모리를 직접 다룰 수 있게 해주는 강력한 도구입니다. 처음에는 어렵게 느껴질 수 있지만, 충분한 연습을 통해 익숙해지면 효율적인 프로그램을 작성할 수 있습니다.
