이진수란?

이진수(Binary)는 0과 1 두 개의 숫자만을 사용하는 수 체계입니다. 컴퓨터는 전기 신호의 ON/OFF 상태로 데이터를 저장하므로, 모든 데이터를 이진수로 표현합니다. 프로그래머가 이진수를 이해하는 것은 필수입니다.

진법 변환

10진수 → 2진수

10진수 13을 2진수로 변환:

13 ÷ 2 = 6 ... 나머지 1
 6 ÷ 2 = 3 ... 나머지 0
 3 ÷ 2 = 1 ... 나머지 1
 1 ÷ 2 = 0 ... 나머지 1

아래에서 위로 읽기: 1101₂

2진수 → 10진수

2진수 1101을 10진수로 변환:

1101₂ = (1 × 2³) + (1 × 2²) + (0 × 2¹) + (1 × 2⁰)
      = (1 × 8) + (1 × 4) + (0 × 2) + (1 × 1)
      = 8 + 4 + 0 + 1
      = 13₁₀

비트 연산자

1. AND 연산 (&)

두 비트가 모두 1일 때만 1을 반환

  1101  (13)
& 1011  (11)
------
  1001  (9)

파이썬: 13 & 11 = 9
C언어:  13 & 11 = 9

2. OR 연산 (|)

두 비트 중 하나라도 1이면 1을 반환

  1101  (13)
| 1011  (11)
------
  1111  (15)

파이썬: 13 | 11 = 15
C언어:  13 | 11 = 15

3. XOR 연산 (^)

두 비트가 다르면 1, 같으면 0을 반환

  1101  (13)
^ 1011  (11)
------
  0110  (6)

파이썬: 13 ^ 11 = 6
C언어:  13 ^ 11 = 6

4. NOT 연산 (~)

비트를 반전시킴 (0→1, 1→0)

~1101 = 0010 (비트 반전)

파이썬: ~13 = -14 (2의 보수 표현 때문)
C언어:  ~13 = -14

5. 왼쪽 시프트 (<<)

비트를 왼쪽으로 이동 (2를 곱하는 효과)

13 << 1 = 26
  1101 << 1 = 11010

13 << 2 = 52
  1101 << 2 = 110100

6. 오른쪽 시프트 (>>)

비트를 오른쪽으로 이동 (2로 나누는 효과)

13 >> 1 = 6
  1101 >> 1 = 110

13 >> 2 = 3
  1101 >> 2 = 11

실전 활용 예제

1. 짝수/홀수 판별

def is_even(n):
    return (n & 1) == 0  # 마지막 비트가 0이면 짝수

print(is_even(4))  # True
print(is_even(5))  # False

2. 두 수 교환 (XOR 활용)

a = 5  # 0101
b = 3  # 0011

a = a ^ b  # a = 0110
b = a ^ b  # b = 0101 (원래 a)
a = a ^ b  # a = 0011 (원래 b)

print(a, b)  # 3 5

3. 특정 비트 설정/해제/토글

# n번째 비트 설정 (1로 만들기)
def set_bit(num, n):
    return num | (1 << n)

# n번째 비트 해제 (0으로 만들기)
def clear_bit(num, n):
    return num & ~(1 << n)

# n번째 비트 토글 (반전)
def toggle_bit(num, n):
    return num ^ (1 << n)

# n번째 비트 확인
def check_bit(num, n):
    return (num >> n) & 1

num = 5  # 0101
print(bin(set_bit(num, 1)))     # 0b111 (7)
print(bin(clear_bit(num, 0)))   # 0b100 (4)
print(bin(toggle_bit(num, 1)))  # 0b111 (7)

4. 2의 거듭제곱 판별

def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0

print(is_power_of_two(16))  # True (10000)
print(is_power_of_two(18))  # False

비트 마스크 (Bit Mask)

여러 플래그를 하나의 정수로 관리할 때 사용합니다. 

READ    = 1  # 0001
WRITE   = 2  # 0010
EXECUTE = 4  # 0100

# 권한 설정
permission = READ | WRITE  # 0011

# 권한 확인
if permission & WRITE:
    print("쓰기 권한 있음")

# 권한 추가
permission = permission | EXECUTE  # 0111

# 권한 제거
permission = permission & ~WRITE   # 0101
