알고리즘 복잡도 분석 - Big O 표기법

기초수학 · 2025.10.30

Big O 표기법이란?

Big O 표기법은 알고리즘의 시간 복잡도(Time Complexity)와 공간 복잡도(Space Complexity)를 나타내는 수학적 표기법입니다. 입력 크기 n이 증가할 때 알고리즘의 실행 시간이나 메모리 사용량이 어떻게 증가하는지를 나타냅니다.

주요 시간 복잡도

표기법 이름 설명 예시
O(1) 상수 시간 입력 크기와 무관하게 일정 배열 인덱스 접근
O(log n) 로그 시간 문제를 절반씩 줄여나감 이진 탐색
O(n) 선형 시간 입력에 비례하여 증가 선형 탐색
O(n log n) 선형 로그 시간 효율적인 정렬 알고리즘 병합 정렬, 퀵 정렬
O(n²) 이차 시간 중첩 반복문 버블 정렬
O(2ⁿ) 지수 시간 매우 느림 피보나치 (재귀)
O(n!) 팩토리얼 시간 극도로 느림 외판원 문제

복잡도 분석 예제

1. O(1) - 상수 시간

def get_first_element(arr):
    return arr[0]  # 배열 크기와 무관하게 항상 1번 실행

# 입력 크기 n에 관계없이 동일한 시간 소요

2. O(n) - 선형 시간

def find_max(arr):
    max_val = arr[0]
    for num in arr:         # n번 반복
        if num > max_val:
            max_val = num
    return max_val

# 배열 크기 n에 비례하여 실행 시간 증가

3. O(n²) - 이차 시간

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):          # n번 반복
        for j in range(n-1):    # n번 반복 (중첩)
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# 중첩 반복문으로 n × n = n² 번 실행

4. O(log n) - 로그 시간

def binary_search(arr, target):
    left, right = 0, len(arr) - 1

    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

# 매 반복마다 탐색 범위가 절반으로 줄어듦
# n → n/2 → n/4 → ... → 1
# 반복 횟수: log₂n

5. O(n log n) - 선형 로그 시간

def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])    # 재귀: log n 깊이
    right = merge_sort(arr[mid:])

    return merge(left, right)       # 병합: O(n)

# 전체: O(n) × O(log n) = O(n log n)

6. O(2ⁿ) - 지수 시간

def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# 재귀 호출이 지수적으로 증가
# fib(5) → 2개 호출 → 4개 호출 → 8개 호출...

복잡도 계산 규칙

1. 상수는 무시

# O(3n) = O(n)
for i in range(n):
    print(i)
for i in range(n):
    print(i)
for i in range(n):
    print(i)

# 3번의 O(n) → O(3n) → O(n)

2. 최고차항만 고려

# O(n² + n + 1) = O(n²)
for i in range(n):          # O(n²)
    for j in range(n):
        print(i, j)

for i in range(n):          # O(n)
    print(i)

print("완료")                # O(1)

# n²이 지배적이므로 O(n²)

3. 독립적인 입력은 따로 표기

# O(n + m)
def process(arr1, arr2):
    for item in arr1:       # O(n)
        print(item)
    for item in arr2:       # O(m)
        print(item)

# 두 배열의 크기가 다르므로 O(n + m)

공간 복잡도

O(1) - 상수 공간

def sum_array(arr):
    total = 0  # 고정 크기 변수
    for num in arr:
        total += num
    return total

# 입력 크기와 무관하게 일정한 메모리 사용

O(n) - 선형 공간

def double_array(arr):
    result = []  # 크기 n인 새 배열
    for num in arr:
        result.append(num * 2)
    return result

# 입력 크기만큼 메모리 사용

실전 팁

  • 반복문 하나: O(n)
  • 중첩 반복문: O(n²), O(n³), ...
  • 절반씩 줄이기: O(log n)
  • 정렬 후 탐색: O(n log n) + O(log n) = O(n log n)
  • 모든 부분집합: O(2ⁿ)
  • 모든 순열: O(n!)

복잡도 비교 (n = 1000일 때)

O(1)        =          1 연산
O(log n)    =         10 연산
O(n)        =      1,000 연산
O(n log n)  =     10,000 연산
O(n²)       =  1,000,000 연산
O(2ⁿ)       = 2¹⁰⁰⁰ 연산 (천문학적 숫자!)

정리

Big O 표기법은 알고리즘의 효율성을 평가하는 핵심 도구입니다. 코딩 테스트나 실무에서 알고리즘을 선택할 때, 입력 크기를 고려하여 적절한 시간 복잡도의 알고리즘을 선택하는 것이 중요합니다. 일반적으로 n이 클 때는 O(n log n) 이하의 알고리즘을 사용해야 합니다.
