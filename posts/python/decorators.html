데코레이터 패턴 이해하기

파이썬 · 2025.10.31

데코레이터란?

데코레이터(Decorator)는 함수나 메서드의 기능을 수정하지 않고 추가 기능을 부여할 수 있는 파이썬의 강력한 기능입니다. 코드의 재사용성을 높이고 관심사의 분리(Separation of Concerns)를 가능하게 합니다.

기본 개념

함수는 일급 객체(First-Class Object)

def greet(name):
    return f"Hello, {name}!"

# 함수를 변수에 할당
say_hello = greet
print(say_hello("Alice"))  # Hello, Alice!

# 함수를 다른 함수에 전달
def call_func(func, name):
    return func(name)

print(call_func(greet, "Bob"))  # Hello, Bob!

파이썬에서 함수는 일급 객체이므로 변수에 할당하거나 다른 함수의 인자로 전달할 수 있습니다.

간단한 데코레이터 만들기

def my_decorator(func):
    def wrapper():
        print("함수 실행 전")
        func()
        print("함수 실행 후")
    return wrapper

def say_hello():
    print("Hello!")

# 데코레이터 적용
say_hello = my_decorator(say_hello)
say_hello()

# 출력:
# 함수 실행 전
# Hello!
# 함수 실행 후

@ 문법 사용하기

def my_decorator(func):
    def wrapper():
        print("함수 실행 전")
        func()
        print("함수 실행 후")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")

say_hello()
# @ 문법은 위의 say_hello = my_decorator(say_hello)와 동일합니다.

인자를 받는 데코레이터

*args, **kwargs 활용

def my_decorator(func):
    def wrapper(*args, **kwargs):
        print(f"함수 이름: {func.__name__}")
        print(f"인자: {args}, {kwargs}")
        result = func(*args, **kwargs)
        print(f"반환값: {result}")
        return result
    return wrapper

@my_decorator
def add(a, b):
    return a + b

@my_decorator
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

add(5, 3)
# 함수 이름: add
# 인자: (5, 3), {}
# 반환값: 8

greet("Alice", greeting="Hi")
# 함수 이름: greet
# 인자: ('Alice',), {'greeting': 'Hi'}
# 반환값: Hi, Alice!

실전 예제

1. 실행 시간 측정 데코레이터

import time

def measure_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} 실행 시간: {end - start:.4f}초")
        return result
    return wrapper

@measure_time
def slow_function():
    time.sleep(1)
    return "완료"

slow_function()
# slow_function 실행 시간: 1.0012초

2. 로깅 데코레이터

def log_function_call(func):
    def wrapper(*args, **kwargs):
        print(f"[LOG] {func.__name__} 호출됨")
        print(f"[LOG] 인자: args={args}, kwargs={kwargs}")
        result = func(*args, **kwargs)
        print(f"[LOG] {func.__name__} 반환: {result}")
        return result
    return wrapper

@log_function_call
def multiply(a, b):
    return a * b

multiply(3, 4)
# [LOG] multiply 호출됨
# [LOG] 인자: args=(3, 4), kwargs={}
# [LOG] multiply 반환: 12

3. 인증 데코레이터

def require_auth(func):
    def wrapper(user, *args, **kwargs):
        if not user.get('is_authenticated'):
            print("권한이 없습니다!")
            return None
        return func(user, *args, **kwargs)
    return wrapper

@require_auth
def delete_post(user, post_id):
    return f"게시글 {post_id} 삭제됨"

user1 = {'name': 'Alice', 'is_authenticated': True}
user2 = {'name': 'Bob', 'is_authenticated': False}

print(delete_post(user1, 123))  # 게시글 123 삭제됨
print(delete_post(user2, 456))  # 권한이 없습니다!

여러 데코레이터 중첩

@decorator1
@decorator2
@decorator3
def my_function():
    pass

# 위 코드는 다음과 같습니다:
# my_function = decorator1(decorator2(decorator3(my_function)))

# 실행 순서: decorator3 → decorator2 → decorator1

functools.wraps 사용하기

from functools import wraps

def my_decorator(func):
    @wraps(func)  # 원본 함수의 메타데이터 보존
    def wrapper(*args, **kwargs):
        """wrapper 함수의 docstring"""
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def example():
    """example 함수의 docstring"""
    pass

print(example.__name__)  # example (wraps 없으면 wrapper)
print(example.__doc__)   # example 함수의 docstring

정리

데코레이터는 코드의 재사용성을 높이고 관심사를 분리하는 데 매우 유용한 도구입니다. 로깅, 인증, 캐싱, 성능 측정 등 다양한 상황에서 활용할 수 있으며, Flask, Django 같은 프레임워크에서도 광범위하게 사용됩니다.
